# mmm-app

小島探險地圖：參考「HEART 政策島」的 3D 低多邊形島嶼地圖，改成小朋友喜歡的七座島。

- 七座六角形島：01 電腦島、02 家庭島（中間）、03 飯店島、04 電動島、05 遊樂園島、06 早餐店島、07 閱讀島
- 「我」：點地面，自己的角色就會走過去，會自動走好朋友橋到別座島
- 島上的小朋友會走來走去、過橋串門子；點他們會說話
- 右側按鈕：全景（回到整張地圖）、角色（換衣服、戴帽子、鏡頭跟著我）、清單（搜尋島上的地點）、時間（白天／傍晚／晚上）
- 探險護照：「我」走到哪座島就蓋章，集滿 7 個章
- 彩蛋：地圖上躲著一位戴黃帽子的小島長

直接用瀏覽器打開 `index.html` 即可（需要網路載入 three.js 和字型）。
